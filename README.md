# Almashlab ekish darsligi

"Almashlab ekishning agroekologik asoslari" elektron darsligi uchun desktop PDF ko'rgich (Electron + pdf.js).

- Bosh sahifa va mavzular mundarijasi (qidiruv bilan)
- Har bir mavzu alohida PDF sifatida ochiladi
- Skroll, zoom (tugmalar / Ctrl + g'ildirak) va sudrab siljitish (pan)

## Ishga tushirish

```bash
npm install
npm start
```

## Windows uchun portable .exe yig'ish

```bash
npm run build
```

Natija: `dist/Almashlab-ekish-darsligi.exe`
